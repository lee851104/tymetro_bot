## 最省力的回覆方式

例如：

> S03 不用「新產」，改成……。
> S12 的一航、T1 都可以。
> C04 問商場分店是對的。
> R03 回答改成……。
> 其他 S 列通過，R 列我下次看。

「其他通過」請附上範圍，例如 S 列、C 列或 R01～R10，避免誤把尚未看的部分視為確認。你提出的修訂會優先於草稿。

## 每種資料要審什麼

| 類型 | 請你主要確認 |
| --- | --- |
| 暱稱 | 旅客是否真的會這樣說？會不會指向其他站、院區、商場？ |
| 追問 | 有沒有漏掉必要資訊？是否反覆詢問已知道的事情？ |
| 查班 | 站碼、方向、車種與停靠判斷是否符合實務？ |
| 回答 | 是否清楚、像站務人員的說法？是否有不該保證的內容？ |
| 規則 | 請附官方來源、生效日／適用條件；不確定可以留待確認。 |

班次時間由指定日期的本機官方快取產生，你不需要逐筆背時刻表。案例中的日期是重現情境使用，並非旅客詢問當下的即時資訊。
