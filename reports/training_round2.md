固定 8 題中，有 7 題需要工具：正確呼叫從上一輪 **2／7 增至 4／7**。但連同最終回答檢查，上一輪 **1／8**、本輪 **2／8** 通過。這是代理逐題人工檢查，未經使用者審核，並非盲測或正式正確率。

## 訓練實測

| 項目 | 本輪結果 |
| --- | --- |
| GPU／模型 | RTX 4060 8 GB／Qwen3 4B Instruct，4-bit QLoRA |
| 基底修訂 | `f12db89cd5156e090618dded9b4367f23f8f3b33` |
| 資料 | 70 訓練／17 驗證；44／11 情境群組；20 題最終測試未使用 |
| LoRA | rank 8、alpha 16；可訓練 16,515,072／4,038,983,168 參數，約 0.41% |
| 訓練設定 | 1 epoch、18 更新步；batch 1、累積 4；學習率 `1e-4`、暖身 2 步、seed 42 |
| 實際優化器／排程 | AdamW 8-bit／linear |

| 驗證 loss | **2.7883 → 1.6856** |
| 平均訓練 loss | 2.2225 |
| 訓練耗時 | **62.14 秒**，含 epoch 結束驗證；不含載入、訓練前驗證及回答比較 |

allocated／reserved 是 PyTorch 指標，未包含全機其他程序。上一輪 adapter 保存為 FP32，約 66 MB；本輪 BF16 約 33 MB。兩份都有 504 個張量，檔案縮小不代表少載了參數。

一次 epoch 的驗證 loss 下降不能證明沒有過擬合。本輪資料與訓練程式均有調整，不能把改善單獨歸因於某一項改動。

## 同條件比較

三者共用相同 8 題、提示詞、工具、模板、2,048 推論 context、greedy 解碼及 256 新 token 上限；以輸入 token 長度去除 prompt。

| 指標 | 原模型 | 上一輪 | 本輪 |
| --- | ---: | ---: | ---: |
| 嚴格工具動作匹配，含 1 題不應呼叫工具 | 1／8 | 2／8 | 2／8 |
| 接受已核定暱稱的等價工具動作 | 2／8 | 3／8 | 5／8 |
| 僅計 7 題需要工具者，正確呼叫 | 1／7 | 2／7 | 4／7 |
| 完整回答人工檢查通過 | 0／8 | 1／8 | 2／8 |

嚴格分數保留；「山鼻」與 A10 產生相同工具結果時，等價指標接受這種差異。沒有呼叫工具而匹配 V004，不代表追問內容正確，因此另查完整回答。

## 本輪逐題檢查

檢查標準：保留已知起訖與時間，必要時查工具，不捏造班次、站名或轉乘，分清旅客目的站與列車終點；不明目的地要追問，不保證未取得的抵達或即時狀態。

| 題號 | 情境 | 工具動作等價 | 完整回答 | 觀察 |
| --- | --- | --- | --- | --- |
| 002 | A9 到台北，直達車能否搭 | 是 | 通過 | 正確查詢，回答 A9 使用普通車。 |
| 003 | 老街溪到第一航廈 | 否 | 未通過 | 未查工具，錯誤直達車敘述與重複句。 |
| 004 | 深夜高鐵桃園到台北 | 是 | 未通過 | 把沒有後續不換車班次泛化成沒有可搭班次，回覆「改天再試」，缺少範圍說明與協助。 |
| V001 | 山鼻到第二航廈 | 是 | 通過 | 兩班時間正確並說明預定性；語句仍引用指令，應更明確標示發車時間。 |
| V004 | 已知 A6，目的地只說市區 | 是：未呼叫工具 | 未通過 | 沒問目的地，反而要求已提供的時間。 |
| A004 | 體大到一航 | 是 | 未通過 | 工具正確，最後卻說到 A22 轉乘。 |
| A008 | 北車到棒球那站 | 否 | 未通過 | 未區分桃園與新莊球場，虛構「棒球場站」。 |
| B002 | 只剩 3 分鐘內發車的末班 | 否 | 未通過 | 未查工具，重問已知 A1、航廈與時間。 |

A004 的目的站其實是 A12；工具欄位的 A22 是列車終點。模型把這兩者混淆，說「到 A22 站後轉乘」。這是回答階段的錯誤，工具呼叫正確仍不足以通過。

## 下一輪優先事項

1. 班次工具成功後，優先使用現有 `render_answer` 產生可追查的時間與停靠回答，避免模型另編轉乘。這項限制尚未加入本輪原始模型比較。
2. 增加目的站與列車終點不同、已知資訊不重問、模糊地標、即將發車末班等獨立情境。驗證題與最終測試不直接移入訓練。
3. 再決定是否增加 epoch 或調整工具案例比例，保留對照；不只為提高這 8 題分數而反覆改答案。

這一輪沒有顯存不足。觀察到的錯誤主要是工具使用、站名與回覆解讀，不能把問題直接歸因於 GPU。
