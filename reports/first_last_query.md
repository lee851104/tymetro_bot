# 自然語言首末班查詢修正

日期：2026-09-22。

## 問題與原因

使用者輸入「A12到A18末班車幾點」，Qwen 展示卻回覆首末班查詢尚未提供。原因是 `timetable_guard.py` 把首班、末班、最早、最晚直接列入未支援清單，在查班表之前就返回限制說明。

## 修正

- Qwen 聊天支援末班／最後一班／最晚、首班／第一班／最早，及已確認路線後的「那末班呢」「那普通車呢」。
- 從整個營運日查詢，先核對方向、目的站停靠與車種，再取首末班，包含隔日凌晨資料。普通表單仍查最近兩班，不沿用聊天的首末班模式。
- 未指定日期時沿用 03:00 營運日分界；明確輸入日期時以該日期的營運日為準。畫面及回答均標示營運日與實際發車日期。
- 首末班時間不因三分鐘緩衝被隱藏。只剩三分鐘會提醒不要趕車，已過時間會明確標示；末班沒有更晚班次時不建議搭不存在的下一班。
- 卡片與聊天直接顯示答案；過去的發車時間不顯示為負數的「分鐘後」。
- 新的 `get_service_boundary` 是應用程式查詢紀錄，未加入原本模型工具 schema；Qwen 原始輸出與查表結果仍分開保留。未重新訓練、修改訓練資料或模型權重。無 GPU 的舊版展示入口仍保留原有能力範圍。
