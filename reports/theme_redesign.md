# 發車看板與深淺主題改版

日期：2026-09-22。

## 設計與操作

- 改為車站發車看板風格：暖白淺色與午夜藍深色、簡潔分隔線、放大的發車時間。
- 保留 22 站路線選站、起訖交換、車種、日期時間、中文聊天及原始模型紀錄。
- 頁首提供淺色／深色按鈕。初次開啟跟隨系統，手動選擇後以 `localStorage` 的 `tymetro.theme` 記住偏好；儲存受限時仍可當次切換。
- 主題在樣式繪製前套用，原生日期時間控制項同步 `color-scheme`。切換不重建表單、不送出新查詢、不清除結果。
- 920px 以下改為單欄，查詢後捲到看板；520px 以下路線圖改為四站一列。尊重減少動畫的系統偏好。

## 後續精簡版面（中間版本，選站方式已於下節調整）

依使用者要求減少頁面長度，移除大幅標題、重複介紹及常駐的大型路線圖。點起訖站會開啟原生選站視窗，選完目的站自動返回；22 站與深淺主題仍保留。

- 窄螢幕成功查班後自動收合條件，顯示起訖、日期時間與車種摘要，可點「修改」重開。
- 完整聊天紀錄預設收合，澄清站名的選項獨立顯示；時間已過、三分鐘內及沒有後續末班的提醒持續顯示在主畫面。
- 同一個 534 × 552 瀏覽器側欄，A12 → A18 末班查詢頁從原本 2,201px 縮為 703px；查詢時刻不同，兩次皆為 9/22 尚未發車的 23:58 末班。
- 檢查 320、390、1280px 寬度沒有橫向溢出。390 × 844 下，選站視窗高度約 642px；桌面 1280 × 800 下可完整呈現查詢與結果。
- 實際 Qwen 表單確認 A12 → A18 普通車、2026-09-22 10:00，顯示 10:12／10:27，選站視窗自動關閉、窄版條件自動收合。
- 以 23:55 查 23:58 末班，確認三分鐘提醒仍可見；「A1到機場下一班幾點」的 A12／A13 澄清按鈕在紀錄收合時仍可操作。
- JavaScript 語法檢查通過；最終瀏覽器 error／warn 清單為空。

## 使用者調整：保留主畫面路線圖

- 完整 22 站路線圖恢復放在起訖欄位下方，直接點站選擇；起訖欄位以藍色／紫色標示目前編輯項目。選完目的站後路線圖仍在原位。
- 移除選站彈窗與窄螢幕查詢後自動收合。查詢條件預設展開，仍可手動收合；保留精簡標題、班次卡片、可展開對話紀錄與深淺色切換。
- 實際以路線圖選 A12 → A18 普通車、2026-09-22 10:00，真實 Qwen 查詢顯示 10:12／10:27，查詢後條件仍展開、22 站仍存在。
- 瀏覽器檢視 1280 × 800 淺色與 390 × 844 深色版，無橫向溢出。手機路線圖高度 432px，採四站一列；完整路線圖保留所需的垂直捲動。
- JavaScript 語法與差異空白檢查通過；瀏覽器 error／warn 清單為空。前節的 703px 頁高僅屬當時的彈窗版本，不適用目前版面。

## 對話辨識與閱讀調整

- 旅客訊息靠右、藍底白字，助手回覆靠左、獨立淺底／深底；每則明確標示「你」或「機捷助手」。內文改為 14px，使用明確文字色，避免繼承紀錄標題的灰色。
- 對話放在輸入框上方，送出訊息即自動展開；最多高 340px，長對話在區塊內捲動，也可手動收合。窄螢幕聊天完成後定位到對話區。
- 實測輸入「A12 到 A18，末班車幾點？」（2026-09-22 23:00），立即出現「你」的訊息，接著以「機捷助手」顯示 23:58 普通車回覆；兩者左右位置與標籤皆已確認。
- 實際檢視 534px 深色與 390px 淺色對話，沒有橫向溢出；22 站路線圖仍展開。JavaScript 語法檢查通過，瀏覽器 error／warn 清單為空。
